O aplikaci

BMS Script Designer (coba.mis.bms.scriptdesigner) je vývojářský nástroj společnosti Mazlušek s.r.o. k editaci, kompilaci a spouštění skriptů a řetězců systému BMS. Je určen dospělým odborníkům.

Komunikace se serverem BMS

Aplikace komunikuje výhradně se serverem BMS, jehož adresu zadáte při prvním spuštění. Přes tento server se přenáší uživatelské jméno a heslo (HTTP Basic; uchovávají se jen v paměti aplikace a nikam se neukládají) nebo přihlášení Entra ID a také obsah skriptů a řetězců BMS. Nastavení spojení se serverem je na vás a na organizaci, která server spravuje.

Data skriptů

Data skriptů a řetězců žijí na serveru BMS, který spravuje vaše organizace. Mazlušek s.r.o. jako provozovatel aplikace k nim nemá přístup a nepoužívá pro aplikaci vlastní servery.

Údaje uložené v zařízení

V zařízení se ukládá pouze adresa serveru. Smaže se odinstalací aplikace nebo vymazáním dat aplikace.

Účet, reklamy a analytika

Aplikace nemá vlastní účet ani registraci. Neobsahuje reklamy ani reklamní identifikátor, žádnou analytiku, hlášení pádů ani Firebase. Žádné údaje nejsou předávány třetím stranám.

Oprávnění

Aplikace vyžaduje pouze oprávnění k přístupu k internetu a ke zjištění stavu sítě. Nepoužívá kameru, mikrofon, polohu, oznámení ani kontakty.
